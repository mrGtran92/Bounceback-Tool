How to use: Keep index.html and tests.html in the same GitHub repo. After any change to index.html, wait ~60 seconds for Pages to rebuild, then reload this page. All tests should show PASS. Any FAIL means a change broke a pathway — investigate before sharing the updated tool.

Two kinds of tests: the scenarios check specific paths from the decision table; the Rules sections walk every possible path through the tool and check rules that must always hold (for example, the NAR never admits before 4 PM). A failing rule shows the first path that breaks it.

To add a scenario: Edit the SCENARIOS array in the script below. Each scenario needs a name, group, service, answers (the question/answer pairs, in the order the tool asks them), and expected (the result key). Add anchor: 'today' or anchor: 'handoff' to also check which day the last-day and working questions ask about.

This page only works when served from GitHub Pages — it fetches index.html over the network, which browsers block for local files. Do not open it by double-clicking from your desktop.
